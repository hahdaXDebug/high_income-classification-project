An Implementation of Regularization and Classification in Classifying High Income Earners¶

Dataset: Adult Income (Census 1994)¶

Sourced from the UCI Machine Learning Repository¶

Abstract¶

This project implemented and compared multiple models, traditional methods with Machine Learning methods, to predict and classify high income earners (citizens who make more than $50k anually). An Exploratory check revealed a massive class imbalance betweeen the high-income earners (75.9%) and low-income earners (24.1%) for all 32561 observations. The six models were tuned and implemented: Logistic Regression, Logistic Regression with the L1, L2 penatly and Elastic Net respectively, Gradient Boosting and Random Forest. The models were evaluated with multiple performance metrics including Accuracy, Prcision, Recall, F1-score, Specificity and the Type 1 and 2 Error rates. Feature importance for all six models were also evaluated; coefficient value served as the indicator for the Logistic Regression models while Mean Decrease in Impurity (MDI) was used for Random Forest and Gradient Boost Classifier. Results from the Regularized Logisitc Regression models incrimental improvements in accuracy and F1-scores for both training and testing sets, with the error rates being similar. The ensemble methods generally performed better despite having slightly higher type 1 error rates, though there is a noticeable difference in type 2 error rates for the Logistic Regression models and the Ensemble methods (Gradient Boost and Random Forest).

# 2. Data preprocessing
def preprocess_census_data(df):
    """Preprocessing for Census Income data"""
    df_processed = df.copy()
    
    # Handle missing values: UCI Census uses '?' for unknowns
    df_processed.replace('?', np.nan, inplace=True)
    
    # Simple imputation
    df_processed['workclass'].fillna(df_processed['workclass'].mode()[0], inplace=True)
    df_processed['occupation'].fillna(df_processed['occupation'].mode()[0], inplace=True)
    df_processed['native-country'].fillna(df_processed['native-country'].mode()[0], inplace=True)
    
    #Simplify Education: Grouping lowereducation levels together
    edu_map = {
        'Preschool': 'Dropout', '1st-4th': 'Dropout', '5th-6th': 'Dropout', '7th-8th': 'Dropout',
        '9th': 'Dropout', '10th': 'Dropout', '11th': 'Dropout', '12th': 'Dropout',
        'HS-grad': 'HS-grad', 'Some-college': 'College', 'Assoc-voc': 'College', 'Assoc-acdm': 'College',
        'Bachelors': 'Bachelors', 'Masters': 'Masters', 'Prof-school': 'Prof-school', 'Doctorate': 'Doctorate'
    }
    df_processed['education_simple'] = df_processed['education'].map(edu_map)
    
    # Simplify Age Groups 
    df_processed['age_group'] = pd.cut(df_processed['age'], 
                                     bins=[0, 25, 45, 65, 100], 
                                     labels=['Young', 'Middle-Aged', 'Senior', 'Old'])
    
    return df_processed

# 3. Feature selection and Encoding
# note: 'fnlwgt' is 'final weight'
def prepare_features(df):
    df_encoded = df.copy()
    
    # Target encoding
    le = LabelEncoder()
    y = le.fit_transform(df_encoded['income']) # >50K becomes 1, <=50K becomes 0
    
    # Select features (Mix of numerical and categorical)
    categorical_cols = ['workclass', 'education_simple', 'marital-status', 'occupation', 'relationship', 'race', 'sex', 'native-country', 'age_group']
    numerical_cols = ['fnlwgt', 'age', 'education-num', 'capital-gain', 'capital-loss', 'hours-per-week']
    
    # Label Encoding for categorical columns to make them usable by Tree methods
    for col in categorical_cols:
        df_encoded[col + '_enc'] = le.fit_transform(df_encoded[col].astype(str))
    
    # Select final feature list
    feature_names = numerical_cols + [col + '_enc' for col in categorical_cols]
    X = df_encoded[feature_names]
    
    return X, y, feature_names

Feature Importance Analysis¶

From the results, the features that appeared consistently across the top 7 lists for the six selected models were hours-per-week, age, education-num and capital-gain. The top 7 features were all consistent across all the same models, that is to say the four iterations of Logistic Regression (baseline, with Lasso, Ridge, and ElasticNet) all had the same top 7.

The consistency in a feature appearing across the top 7 for all eight models selected is a sign of importance as a predictor, regardless of the choice to use of traditional methods like Logistic Regression or a tree-based method (Random Forest and Gradient Boosting). While there were four features that appeared in the top 7 across all six models selected, there were also features that only appeared in the tree-based models such as Random Forest and Gradient Boosting. Features that never appeared across the top 7 for all models can perhaps be regarded as redundant noise.

def get_metrics(y_true, y_pred, model_name, dataset_type):
    # Extract components of the confusion matrix
    cm = confusion_matrix(y_true, y_pred)
    # Ensure it handles binary classification correctly
    if cm.shape == (2, 2):
        tn, fp, fn, tp = cm.ravel()
    else:
        tn, fp, fn, tp = 0, 0, 0, 0 # Fallback for edge cases
        
    # Calculate additional metrics
    specificity = tn / (tn + fp) if (tn + fp) > 0 else 0
    type1_error = fp / (tn + fp) if (tn + fp) > 0 else 0  # False Positive Rate
    type2_error = fn / (tp + fn) if (tp + fn) > 0 else 0  # False Negative Rate
    
    return {
        "Model": model_name,
        "Dataset": dataset_type,
        "Accuracy": accuracy_score(y_true, y_pred),
        "Precision": precision_score(y_true, y_pred, zero_division=0),
        "Recall": recall_score(y_true, y_pred, zero_division=0),
        "F1-Score": f1_score(y_true, y_pred, zero_division=0),
        # Multiply by 100 to format as percentages
        "Specificity (%)": specificity * 100,
        "Type 1 Error FPR (%)": type1_error * 100,
        "Type 2 Error FNR (%)": type2_error * 100
    }

5. Model Recommendation¶

Recommended Model: Gradient Boosting¶

Among the models, the Gradient Boosted model lands a recommendation. The recommended model has the highest accuracy while not suffering from overfitting like the other ensembled-based model, offering the best predictive power with the highest F1-score. The consistent high marks in the performance metrics make it the best model for this dataset. In terms of interpretability, the tree-based models offer better intuitive interpretability in its list of feature importance, and the hyperparameter tuning options allow for greater control.

The Gradient Boosted model also has the second highest type 1 error rate at around 5.93% despite having the lowest type 2 error rate at around 32.59%. All models had type 1 error rates between 5.52% and 6%. In the context of this dataset, minimizing type 1 error is generally more important since a type 1 error is likely to be more detrimental in real world scenarios. A False Positive (Type 1 Error) indicates that the model predicts an individual earns >50K, but they actually earn ≤50K while a False Negative (Type 2 Error) indicates that the model predicts an individual earns ≤50K, but they actually earn >50K. When it comes to income, the model is better off minimizing Type 1 error since there are likely more situations where a false positive would be detrimental. The recommended model is the best of both worlds, having a similiar type 1 error to the other models while having the lowest type 2 error. This recommended model is more generalizable.
